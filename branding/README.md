# Pulse brand assets

## Core palette
- Pulse Green: `#3ECF8E`
- Pulse Charcoal: `#0B1114`
- App Background: `#090F12`
- White: `#FFFFFF`

## Usage
- `pulse-mark-dark.svg`: light backgrounds
- `pulse-mark-light.svg`: dark backgrounds
- `pulse-mark-mono.svg`: single-color applications
- `pulse-app-icon.svg`: square app/avatar usage
- `pulse-lockup.svg`: horizontal lockup on light backgrounds
- `pulse-lockup-light.svg`: horizontal lockup on dark backgrounds

Keep at least one outer-bar width of clear space around the mark. Do not stretch, rotate, recolor individual bars, or add effects.
